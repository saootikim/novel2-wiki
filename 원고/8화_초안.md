# 8화. 던전(1) (초안)

유림은 한동안 계속 썼다.

헌터 제도가 생겼다.

던전 등급이 나뉘었다.

약한 던전부터 강한 던전까지.

엔터를 칠 때마다 꽂혔다.

장면이 보였다.

사라졌다.

한 줄을 쓸 때마다 관자놀이가 울렸다. 코 밑을 닦은 휴지가 책상 위에 쌓여 갔다.

그러다 멈췄다.

*참여자.*

유림은 상태창 파일을 열었다.

```
참여 방식     : 참여자  (확정)
```

*세계 안으로 들어간다.*

선택할 때 읽었던 문장이었다.

근데 지금까지 들어간 적이 없었다.

글로만 바꾸고 있었다.

*직접 들어가면 어떻게 되는 거지.*

유림은 빈 문서를 열었다.

커서가 깜빡였다.

손가락이 움직였다.

**유림은 던전 앞에 서 있었다.**

엔터.

꽂혔다.

근데 이번엔 달랐다.

장면이 보이는 게 아니었다.

머릿속이 아니었다.

눈앞이 하얘졌다.

눈을 감았다.

유림은 눈을 떴다.

무릎이 꺾였다. 유림은 그대로 바닥에 주저앉았다.

코 밑이 뜨거웠다. 손등으로 훔치자 붉은 게 길게 묻어 나왔다.

머리가 깨질 것 같았다. 그래도 정신은 붙어 있었다.

차가운 공기가 느껴졌다.

발밑이 딱딱했다.

*……여기가 어디야.*

고개를 들었다.

앞에 문이 있었다.

검은 균열.

공기가 일그러진 것.

던전이었다.

유림은 뒤를 돌아봤다.

서울이었다.

강남 한복판.

사람들이 멀리서 웅성거리고 있었다.

경찰 통제선이 쳐져 있었다.

핸드폰을 든 사람들.

카메라를 든 사람들.

*진짜로 들어왔다.*

손이 떨렸다.

아래를 봤다.

노트북이 없었다.

키보드가 없었다.

손에 아무것도 없었다.

*어떻게 돌아가지.*

그때 손끝이 따뜻해졌다.

유림은 손을 봤다.

손가락 끝이 희미하게 빛나고 있었다.

뭔가 머릿속으로 꽂혔다.

눈앞에 창이 떴다.

노트북 화면이 아니었다.

공중에 떠 있었다.

아무것도 없는 허공에.

```
═══════════════════════
        작가. 유림
═══════════════════════

[ 고정 항목 ]

신분          : A-1의 작가
등급          : 무명
고유 스킬     : 열람 / 각인

═══════════════════════

[ 선택 항목 ]

참여 방식     : 참여자  (확정)
              : ???  [ 잠김 ]
              : ???  [ 잠김 ]
              : ???  [ 잠김 ]

═══════════════════════
```

유림은 허공에 떠 있는 창을 멍하니 봤다.

*홀로그램이잖아.*

손을 뻗었다.

창이 손끝에 반응했다.

글씨가 선명해졌다.

*여기서도 쓸 수 있다는 거구나.*

유림은 천천히 숨을 들이마셨다.

앞에 던전이 있었다.

자신이 만든 던전이었다.

*들어가볼까.*

발이 움직였다.

경찰 통제선 쪽에서 누군가 소리를 질렀다.

"거기, 일반인은 던전 접근 금지입니다!"

유림은 멈추지 않았다.

던전 문 앞에 섰다.

공기가 일그러진 경계선.

안쪽은 어두웠다.

손끝이 빛났다.

*내가 만든 세계잖아.*

유림은 안으로 들어갔다.
