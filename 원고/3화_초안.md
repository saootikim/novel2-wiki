# 3화. 작가. 유림 (초안)

손이 멈추질 않았다.

엄마 다음엔 아빠였다.

아빠 다음엔 대학 때 친구였다.

유림은 한 명씩 이름을 떠올리며 타이핑했다.

작은 것들이었다.

오늘 밥을 잘 먹었으면 좋겠다.

오늘은 덜 외로웠으면 좋겠다.

오늘만큼은 좋은 일이 하나쯤 있었으면 좋겠다.

엔터를 칠 때마다 머릿속으로 꽂혔다.

장면이 보였다.

그리고 사라졌다.

유림은 한참 뒤에야 키보드에서 손을 뗐다.

등받이에 기댔다.

*언제부터 이러고 있었지.*

시계를 봤다.

새벽 4시 32분.

그때 메일 알림이 왔다.

유림은 반사적으로 화면을 봤다.

또 그 주소였다.

알파벳과 숫자가 뒤섞인, 도메인을 알 수 없는 주소.

제목은 한 줄.

작가. 유림 — 파일을 전송합니다.

클릭했다.

첨부파일이 하나 있었다.

파일 이름을 보는 순간 유림은 눈을 가늘게 떴다.

작가. 유림.txt

*……내 이름이잖아.*

파일을 열었다.

텍스트 파일이었다.

흰 배경에 검은 글씨.

근데 형식이 이상했다.

소설 파일이랑 똑같은 텍스트 파일인데, 표처럼 정리되어 있었다.

```
═══════════════════════
        작가. 유림
═══════════════════════
[ 고정 항목 ]
신분          : A-1의 작가
등급          : 무명
고유 스킬     : 열람 / 각인
═══════════════════════
[ 선택 항목 ]
참여 방식     : 미정  ← 선택 필요
역할          : 미정  ← 선택 필요
세계 내 능력  : 미정  ← 선택 필요
              : ???  [ 잠김 ]
              : ???  [ 잠김 ]
              : ???  [ 잠김 ]
═══════════════════════
```

유림은 화면을 천천히 읽었다.

열람은 알겠는데.

*각인.*

아까 이재현 장면이 머릿속에 꽂혔던 거.

그게 각인이었구나.

그리고 선택 항목.

유림은 참여 방식에서 멈췄다.

미정.

클릭해봤다.

커서가 그 줄 위에서 깜빡였다.

그리고 텍스트가 바뀌었다.

```
참여 방식     :
  ->관찰자   — 세계를 바꾸되 직접 개입하지 않는다
  ->참여자   — 세계 안으로 들어간다

  * 이 선택은 되돌릴 수 없습니다
```

유림은 잠시 멈췄다.

*세계 안으로 들어간다.*

그 말이 머릿속에서 맴돌았다.

지금도 충분히 이상한 상황인데.

직접 들어간다는 건 또 뭔 소리야.

근데.

유림은 화면을 봤다.

메일 속 수백 명의 이름들.

엄마.

아빠.

이재현.

지금은 그냥 글로 쓰고 있지만.

*직접 들어갈 수 있다면.*

유림은 커서를 움직였다.

->참여자

클릭.

파일이 업데이트됐다.

```
참여 방식     : 참여자 (확정)
```

파일이 한 번 깜빡였다.

그리고 전체가 업데이트됐다.

```
═══════════════════════
        작가. 유림
═══════════════════════
[ 고정 항목 ]
신분          : A-1의 작가
등급          : 무명
고유 스킬     : 열람 / 각인
═══════════════════════
[ 선택 항목 ]
참여 방식     : 참여자  (확정)
              : ???  [ 잠김 ]
              : ???  [ 잠김 ]
              : ???  [ 잠김 ]
═══════════════════════
```

역할도, 세계 내 능력도 사라져 있었다.

*……어디 갔지.*

유림은 파일을 닫았다.

그리고 잠시 천장을 봤다.

참여자.

세계 안으로 들어간다는 게 어떤 건지는 모르겠지만.

유림은 다시 키보드 앞으로 몸을 당겼다.

커서가 깜빡이고 있었다.

*일단 써보면 알겠지.*
