# 아웃라인 51~100화 (안)

> 2부 「신진」 후반. 확정 틀([[스토리라인_전체]]): 다른 던전의 벽 문장으로 앞 작가의 흔적을 모은다 → 100화 1차 결말 지점("A-1은 처음이 아니다" + 유림이 "그래도 끝까지 쓰겠다"를 고른다). 한 화 3,000~4,000자.

## 「남은 벽」 51~58화 — 재현과 함께 가는 원정
| 화 | 가제 | 한 줄 |
|---|---|---|
| 51 | 빈 문서 | 50화 다음 날. 유림이 자기 소설 빈 문서에 처음으로 한 줄을 씀(꽂히지 않는 그냥 소설). 숫자 반응 없음 — "여기 쓰는 건 안 읽힌다" |
| 52 | 계획 | 재현과 남은 증언 장소(전남·강원·부산·해외 2) 정리. 메일은 "필요할 때만" 규칙으로 검색 |
| 53~54 | 던전(9)(10) | 전남 던전. 규칙 셋째대로 재현이 밖에서 시간 체크. 여섯째 벽 문장 |
| 55 | 정은비 | 정은비 재등장 — 트레이싱 종이 대신 사진에 안 찍히는 글자를 "손으로 베끼는" 협력 제안 |
| 56~57 | 던전(11)(12) | 강원 던전. 일곱째 벽 문장. 각인에 쓰지 않은 장면이 길어짐(빈방의 밤) |
| 58 | 일곱 줄 | 편지 일곱 줄을 이어 봄. 편지가 "누군가에게 넘겨주는 글"이라는 게 보임 |

## 「이사」 59~66화 — 엄마·아빠가 빈방으로
| 화 | 가제 | 한 줄 |
|---|---|---|
| 59 | 이사 | 부모가 언덕 위 3층으로 이사. 유림이 열쇠를 건넴 |
| 60 | 수술 | 엄마 무릎 수술. 유림이 막는 문장을 쓸지 고민 — 쓰지 않기로(재현과 상의, 규칙 둘째) |
| 61 | 창가 | 아빠가 창가에서 유림 원룸 불을 봄. 아빠 줄에 "이번엔 불이 켜져 있다" |
| 62 | 서지안 | 서지안 재등장. 엄마 병원에서 마주침 — 서지안의 엄마도 같은 병원 |
| 63 | 박정호 | 박정호가 협회 내부 기록 "벽에 글자를 본다는 민간인 제보"를 들고 옴 |
| 64 | 다섯 사람 | 정체를 아는 사람은 재현뿐. 나머지는 각자 조각만 아는 상태로 한자리 (유림은 끝까지 말 안 함) |
| 65 | 할머니 | 1층 할머니가 빈방의 앞 사람 얘기를 처음 길게 함 — "그 사람도 친구가 하나 있었어" |
| 66 | 친구 | 앞 작가에게도 동료가 있었다. 재현이 자기 줄에서 "전에도 본 것 같은" 기억을 다시 봄 |

| 69 | 해외 | 해외 두 곳은 직접 못 감 — 메일로 해외 헌터 줄을 검색, 정은비 인맥으로 손 베낀 사본 입수 |
| 70~71 | 아홉째·열째 | 해외 사본 두 줄. 편지가 거의 다 모임, 마지막 한 줄 비어 있음 |
| 72 | 잠긴 항목 | 상태창 "세계 내 능력 : ???"가 열림 (이름은 확인 필요) |

| 76 | 빈방의 밤 | 각인 속 쓰지 않은 장면이 처음 끝까지 보임: 앞 작가가 창틀에 "제출"을 긁고 엔터를 누르는 밤 |
| 77 | 다음 사람 | 그 장면 끝에 앞 작가가 "다음 사람"의 이름을 고름 — 그게 유림 |
| 78 | 고른 이유 | 앞 작가의 마지막 줄: 왜 유림을 골랐는지 (내용 확인 필요) |

| 81~84 | 작게, 많이 | 넷째 벽 문장대로 크게 쓰지 않고, 막는 문장 여러 개를 미리·작게. 재현이 지휘, 박정호·정은비가 현장 |

## 큰 결정 (2026-11-08 확정, 2·5·6은 안대로)
1. 앞 작가 = 단정 안 함, 글씨만 닮음 (확정)
2. 해외 벽 문장 두 곳 — 직접 안 가고 메일·사본으로 (안)
3. 72화 세계 내 능력 = 퇴고: 이미 쓴 자기 문장을 고칠 수 있음, 남의 일어난 일은 여전히 못 지움 (확정)
4. 99화 새 등급 = 주목 (확정)
5. 확정 복선 16 "상태창 맨 아래 잠긴 줄 = 제출(3부 초)"과 50화 "원고 : 제출 전" 줄 정리 — 안: 50화 줄은 메일과 같은 상태 표시, 잠긴 "제출" 버튼은 3부 초 그대로
6. 64화: 재현 말고 다른 사람(정은비·박정호·서지안)에게는 2부 동안 정체를 말하지 않음 (안)
